# data/ 目录说明

本目录用于存放项目使用的数据集，但 **数据集本体不提交到 Git**（已被
`.gitignore` 排除，仅保留本 README）。

## 数据集获取方式

本项目优先使用规模小、CPU 友好的公开数据集，由 `torchvision.datasets`
按需下载。首次运行时数据会缓存到系统默认目录（例如 Windows 下的
`~/.cache/torch`），不会写入本项目 `data/` 目录。

| 数据集 | 用途 | 规模 | 许可/来源 |
| --- | --- | --- | --- |
| FashionMNIST | 主数据集：MLP / CNN 图像分类（阶段 C） | 28×28 灰度，60k 训练 / 10k 测试，约 30 MB | [GitHub](https://github.com/zalandoresearch/fashion-mnist)（MIT） |
| CIFAR-10 | 进阶数据集：彩色图像分类（阶段 C 后续） | 32×32×3，50k 训练 / 10k 测试，约 170 MB | [官方](https://www.cs.toronto.edu/~kriz/cifar.html) |

> 阶段 E / F（图像通信、语义通信原型）所需图像会从上述数据集的测试子集中
> 选取少量样本，避免额外下载大型数据。

## 存储约定

- 数据集一律放在系统缓存目录，**不要手动复制进本仓库的 `data/`**。
- 如需在本地固定数据集路径，可自行创建 `data/` 下的子目录存放，但注意该
  目录内容已被 `.gitignore` 忽略，不会进入版本控制。

## 隐私与合规

- 本项目只使用公开学术数据集，不含个人信息。
- 若未来引入任何含隐私信息的数据，必须先脱敏、取得授权，并在提交前二次
  确认不会被 `git` 追踪。
